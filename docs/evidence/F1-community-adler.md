# 证据卡：F1 共同体感 ← 阿德勒社会兴趣

## 概念

阿德勒「社会兴趣 / Gemeinschaftsgefühl」：个体感到自己属于共同体、愿意合作与贡献的程度。
它不是外向热闹，而是**归属 + 互惠 + 可协作**。

## 盘面代理（可计算）

关系子图宫位（本命命名层）：

- 交友（含传统仆役/朋友职能）
- 夫妻
- 迁移（社会场域出入）

可选扩展（v1 再开）：仆役别名、官禄中的组织协作边——**MVP 不开**，防因子膨胀。

## 计分直觉

- 禄 / 科 / 权流入关系子图 → 抬高共同体感
- 忌 / 自化忌切割关系子图 → 压低
- 关系宫空且强依赖借对 → 归属摩擦（轻罚）

## 读法（给 Agent）

- 高：协作归属势能强；可觉察动作偏「维护连边」
- 中：拉锯；标出正负边并存处
- 低：割裂势能；可觉察动作偏「先修哪一条忌压边」

## 护栏

- 六亲细节标「参考受限」
- 不把低分说成「命中注定孤独」
- 社会兴趣是心理学启发，不是紫微古籍原术语；输出须标明「代理指标」
