# 设计笔记（2026-10-27）

## 产品切口

先做「命盘韧性仪表盘」最小闭环，不做全知算命网站。

MVP：

1. chart JSON → 超图
2. 三维指标 + keystone + 忌压宫位
3. Agent 按契约解释
4. 检索只打本地索引

## 分层

- L0 计算：上游排盘引擎（确定性）
- L1 网络：`chart2hypergraph.py`（可验证）
- L2 语义：xerj/zvec 检索 + LLM 翻译（概率性）

## 为什么不用全量 v4.0

877 万段 / 56.6GB 适合做研究语料，不适合当 Agent 默认依赖。

默认策略：

- 规则层：格局名、四化表、三方四正、倪师短引索引（小）
- 语义层：按年切片或按结构模板抽样进 zvec
- 全量仅离线批处理时挂载
