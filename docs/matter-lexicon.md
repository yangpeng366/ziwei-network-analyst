## 兜底：问法没被识别时

问题落到 `general`（`matched=false`）时，CLI 与静态站显示同一句话，
模板唯一存放于 catalog.json 的 `fallback_hint`：

> 问法没被识别，可试试：事业 / 工作 / 职场 / 升迁 / 钱 / 财 / 收入 / 投资 / 感情 / 恋爱 / 相亲 / 结婚……；也可以换个更具体的说法（说清做哪件事、想解决什么）。

## 整体态势（general）· 兜底类

- 兜底身份：`fallback=true`。打分阶段**跳过**该类的关键词，只有其他类别一个都没命中（含问题为空、只有时间词）时才启用。
- 启用后的口径：`matched=false`，事实卡只给十二宫一览 + 宫义速查，不再逐宫铺开；并附 `suggestions`（可试说法）与 `hint`（问法没被识别的提示）。
- 相关宫位：命宫 / 官禄 / 夫妻 / 财帛
- 关注因子：共同体感 / 承重集中 / 冲击脆弱 / 节律窗口
- 关注镜头：不锁单一事项时，仍用四因子总览，再点最热宫位。
- 关键词（7 个，仅作文案参考：打分阶段跳过兜底类，这些词不会命中任何类别）：整体、运势、大方向、今年、怎么办、看看盘、命盘

示例问法（词均取自本类关键词）：

1. 今年整体怎么样？
2. 想问问运势的事，什么时候合适？
3. 大方向和今年，哪个更该先动？
