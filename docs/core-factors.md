# 核心因素（普遍子空间）

> 决策口径（2026-10-27）：项目不追求「复杂网络论文大全 × 紫微百科」。
> 对标「普遍权重子空间」与阿德勒「社会兴趣」——先抓住少数可迁移因子，再谈外围装饰。
> 锚点文：[普遍权重子空间](https://mp.weixin.qq.com/s/zzNOE58vG9ACQhodfCBt-A)

## 一句话

命盘解读的有效复杂度，应被压到 **4 个核心因素**。其余格局名、断语、流派叙事都是可替换的外围参数。

## 四因子（v0.1）

| ID | 名称 | 直觉 | 盘上取什么 | 输出说什么 |
|---|---|---|---|---|
| F1 | **共同体感** Community | 阿德勒社会兴趣：合作/贡献/归属，而非外向热闹 | 交友·夫妻·迁移（交友含仆役职能）；**关系宫内**禄/科/权算满权，三方溢出弱计；忌直接切割重罚 | 关系网络是协作型还是割裂型；可干预的「连边」 |
| F2 | **承重星** Keystone | 生态关键种 / d·s 韧性 | 主星 `state × degree`，忌/权加权 | 哪 2～3 颗星在扛系统；倒哪颗会雪崩 |
| F3 | **冲击脆弱** Fragility | 忌 = 关键失效算子 | 忌/自化忌覆盖的宫与三方路径 | 风险带宽：哪条链路最脆 |
| F4 | **节律窗口** Tempo | 大限 = 时序重连，不是每年吉凶标签 | 当前/相邻大限层对 F1–F3 的改写幅度 | 是否接近结构重写窗口 |

## 校准快照（合成对照盘）

| fixture | F1 | 期望读法 |
|---|---|---|
| `calibration/community-high.json` | ~0.70 | 偏协作归属 |
| `fixtures/sample-chart.json` | ~0.39 | 拉锯 |
| `calibration/community-low.json` | ~0.30 | 偏割裂 |

阈值：`≥0.55` 协作 / `≥0.35` 拉锯 / 其余割裂。

计分只认 **本命 + 当前大限 + 流年** 活跃层；历史大限留在超图里做时间线，不进 F1/F3 打分。

回归：`python scripts/test-f1-regression.py`（合成盘序关系）。
真实盘只做分布巡检：`python scripts/inspect-real-distribution.py`。
**语料只引用位置、作 prompt 参考**；不对语料软标签冻权重。

## 明确不做（MVP 外）

- 博弈图四拓扑全分类展览
- LLM 流派回声室研究
- 67 万盘全量聚类产品化
- 13 维断语整库默认加载
- 「合盘对抗模拟器」在单盘四因子稳定前不上

## 与上游的边界

- 排盘、四化、亮度：仍只信 `ziwei-doushu` 引擎
- 四因子：本仓库计算；LLM 只翻译因子，不发明因子
- 检索：xerj/zvec 只服务「给因子找证据」，不服务「再讲一遍全书」

## 成功标准

一张盘出来，用户 30 秒内能回答：

1. 我的关系网偏合作还是割裂？（F1）
2. 谁在扛事？（F2）
3. 哪条线最怕冲击？（F3）
4. 这十年是不是结构重写期？（F4）
